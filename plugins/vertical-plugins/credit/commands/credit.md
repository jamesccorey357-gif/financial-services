description: Credit analysis of an issuer -- leverage, coverage, liquidity, risk band
argument-hint: "[ticker(s) or issuer name]"
---

Load the `credit-analysis` skill to assess the issuer's leverage, coverage, cash flow, and liquidity, map them to financial-risk bands, and set out what would move the credit.

If tickers are provided, run the metrics script on all of them. Otherwise ask the user for the issuer and any financials they have.
